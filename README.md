# Visual Canvas

An infinite whiteboard for Obsidian that opens your existing `.canvas` files.

Status: in development (phase 2 of 6 — the board foundation).

- Reads and writes Obsidian's own JSON Canvas files. Anything Visual Canvas adds lives in extra
  `vc` fields, so the core Canvas still opens every board.
- You can switch any board between Visual Canvas and the core Canvas from its header.

Network use: none so far. (Bookmark previews, added later, will fetch the pages you bookmark.)
